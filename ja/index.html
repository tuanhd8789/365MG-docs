Microsoft 365 ↔ Google Workspace 移行

会社全体の Microsoft 365 を、メッセージを 1 通も失わずに移行

365MG は、お使いの Windows PC から、Microsoft 365 と Google Workspace の間でメール、連絡先、予定表、OneDrive と Google ドライブ、共有ドライブ、グループをどの方向にもコピーします。すべてのアイテムをジャーナルに記録し、再実行しても重複せず、データの損失や重複につながる選択が必要な場合は停止してお客様に確認します。

主な機能

🏢

Microsoft 365 と Google Workspace

任意の数の Microsoft 365 テナントと Google Workspace アカウントを接続し、どの方向にもコピーできます: Microsoft ↔ Google、Microsoft → Microsoft、Google → Google。

🧭

ガイド付きキャンペーン ウィザード

フィルターで移行元ユーザーを選択し、移行先ユーザーと自動で照合し、移行先ドメインとライセンスを一括で割り当て、不足しているユーザーを作成します。

✉️

メール、連絡先、予定表

Exchange メールボックス API を通じてすべてのアイテムをフォルダーごとにエクスポートおよびインポートします。アイテムごとのジャーナルにより、停止した実行は中断した箇所から続行されます。

☁️

ハッシュ確認付きの OneDrive

ファイルとフォルダーをコピーし、作成日時と更新日時を保持し、すべてのファイルを quickXorHash で検証し、大きなファイルは再開可能な 64 MB 単位の範囲でダウンロードします。

👥

メール グループ

配布リストとメールが有効なグループを、同じエイリアス、メンバー、所有者を持つ Microsoft 365 グループとして再作成します。

🌊

ウェーブとドライ ラン

ユーザーをウェーブに分割し、何も書き込まずに実行時のコピー量を集計してから実際にコピーし、切り替えまでスケジュールに従って同期を続けます。

✋

推測する前に確認

移行先のメールボックスや OneDrive がない、ユーザーが再作成された、結果が不明なアイテムがある、といった場合は、それぞれを解決する操作とともに「判断が必要」リストに表示されます。

📊

レポート

ユーザー別および合計の移行元とコピー済みの比較、確認が必要なユーザー、グループ、メモを表示します。単一の HTML ページまたは CSV としてエクスポートできます。

🌐

9 つの言語

English、Tiếng Việt、简体中文、한국어、日本語、Deutsch、Русский、हिन्दी、العربية (右から左)。

移行の流れ

  1. 両方のクラウドを接続Microsoft のグローバル管理者または Google の特権管理者としてサインインすると、365MG がアクセス許可を確認し、データ移行アプリ (アカウント) を設定します。
  2. キャンペーンを計画ユーザーを選択し、移行先を照合し、コンテンツ、スレッド、スケジュールを選択します。
  3. 移行先を準備1 回のクリックで不足しているユーザーを作成し、ライセンスを割り当てます。
  4. ドライ ランの後にコピーまず件数を集計し、次にウェーブごとにコピーします。いつでも一時停止と再開ができます。
  5. 判断とレポート判断が必要な項目を解決し、切り替えまで再同期し、レポートをエクスポートします。

実際の移行で得た教訓から設計

すべての安全策は、350 ユーザーの会社を移行した際に発生した問題に基づいています。途中でライセンスを失ったメールボックス、まだ存在しなかった OneDrive、送信中に切断された接続などです。

  • 各アイテムは送信前にジャーナルに記録されます。停止した実行は再開され、繰り返されることはありません。
  • 結果が不明なアイテムが黙って再送信されることはありません。お客様が選択します。
  • 既にメールがある移行先メールボックスには、許可しない限りコピーしません。
  • データはお使いの PC のみを経由します。一時ファイルは指定したドライブに置かれ、アップロード直後に削除されます。
  • 更新プログラムには署名があります。アプリは作成者が署名したビルドのみをインストールします。
